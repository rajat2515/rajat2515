## Featured projects

### 🏥 [FedMedSeg](https://github.com/rajat2515/FedMedSeg): Privacy-preserving pneumonia detection
Federated medical image segmentation (MobileNetV2-UNet) across Non-IID hospital nodes, so raw patient X-rays never leave the hospital.
- FedProx reached a Dice score of **0.6449**, ahead of FedAvg (0.6334) and isolated training (0.6057)
- Differential privacy with Opacus (ε = 8.0) and 75% model compression (12.8 MB → 3.2 MB)
- `Python` `PyTorch` `Flower` `Opacus` `Streamlit`

### 🧩 [AR Sudoku Solver](https://github.com/rajat2515/sudoku-solver): Real-time augmented reality solver
Detects a Sudoku grid in a live webcam feed, reads the digits with a custom CNN, solves it, and projects the answer back onto the paper.
- OpenCV pipeline with adaptive thresholding, Hough lines, and perspective warping
- Constraint-propagation solver (MRV heuristic) that solves a 9×9 grid in under 0.01 s
- `Python` `PyTorch` `OpenCV` `NumPy`

### 🧠 [MemoryLearn](https://github.com/rajat2515/MemoryLearn): AI-enhanced virtual memory management
Simulator comparing FIFO, LRU, Clock, and Optimal page replacement, with an ML model that picks the best algorithm for the current workload.
- **94%** algorithm-selection accuracy, with 15–25% fewer page faults
- `Python` `scikit-learn` `Pandas` `Matplotlib`

### ♻️ [E-Waste Classification](https://github.com/rajat2515/E-Waste-Classification): Image classifier for 10 e-waste categories
EfficientNetV2B0 classifier built during my AI research internship at Edunet Foundation.
- **96.13%** test accuracy with learning rate scheduling
- `Python` `PyTorch` `EfficientNetV2`
